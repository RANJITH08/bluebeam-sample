# OpenMark FEATURES (source of truth). Mark [x] when done and tested.

## P0 CORE
[x] File: Open, Open Recent, Save, Save As, Close, Print, Export PNG/JPG
[ ] View: Fit Page, Fit Width, Actual Size, Single/Continuous/Side-by-side,
    Rotate View, Rulers, Grid + Snap to Grid, Dimmer, Split view (2 docs)
[ ] Edit: Undo/Redo, Cut/Copy/Paste, Paste in Place, Delete, Select, Select All,
    Lasso select, Pan, Snapshot (copy region), Format Painter
[ ] Markup tools: Text Box, Typewriter, Note, Callout, Pen, Highlight, Eraser,
    Line, Arrow, Arc, Polyline, Dimension, Rectangle, Ellipse, Polygon, Cloud,
    Cloud+ (cloud + callout), Image, Flag, Stamp
[ ] Properties: line color/width/style/endpoints, fill, opacity, font/size/style,
    subject, author, comment, replies, status (Open/Pending/Completed), layer
[ ] Reuse toggle (keep tool active), Properties toolbar that changes by selection
[ ] Panels: Thumbnails, Bookmarks, Markups List, Properties, Search, Layers, Flags
    (dockable left/right/bottom, show/hide, auto-hide)
[ ] Markups List: sortable/filterable columns, status, replies, jump-to, CSV export
[ ] Status bar: page x/y, scale, cursor coords, snap toggles

## P1 TAKEOFF
[ ] Set Scale (calibrate by known distance, per page, unit + precision)
[ ] Length, Polylength, Area, Perimeter, Diameter, Center Radius, 3-Point Radius,
    Angle, Volume (area x depth), Polygon Cutout, Ellipse Cutout, Count
[ ] Measurements panel: totals by subject, units, precision, CSV export
[ ] Sketch to Scale: Rectangle, Polygon, Ellipse, Polyline

## P2 DOCUMENT
[ ] Rotate/Insert blank/Insert from PDF/Extract/Split/Delete/Replace/Crop pages
[ ] Page labels, Headers & Footers, Document Properties, Reduce file size
[ ] Flatten markups (with optional recovery data), Publish As (flattened copy)
[ ] Hyperlinks, File Attachment, Bookmarks editor
[ ] Profiles: save/load workspace layout, Keyboard shortcuts editor

## P3 POWER
[ ] Tool Chest: save any markup to a tool set, drag/click to reuse, import/export
[ ] Compare Documents (pixel diff -> markup), Overlay Pages (2 colors)
[ ] Batch: Rotate, Split, Headers/Footers, Flatten, Stamp, Print, Summary
[ ] Redaction: mark, apply (burn into page)
[ ] Forms: text/check/radio/dropdown fields, fill, save
[ ] OCR via bundled tesseract.js (offline language data shipped locally)
[ ] Spaces (named regions with area totals)
